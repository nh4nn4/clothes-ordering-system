# clothes-ordering-system
This is a final year group project titled "Clothes Ordering System" made by 4 diploma of computer science students. 

How to set up:
1. Unzip all necessary files and import the .sql file to phpMyAdmin. 

2. Then, update the coding for these files to match the ports that you use on XAMPP: 
   login.php, register.php, cust-homepage.php, admin-hub.php, employee-hub.php and DBConnection.php (There might be some files that are not listed that may or may not require you to do this, so be aware)

3. You're now good to go!

Project Description:
This is a clothes ordering system for a clothes retail store called "Waveline Apparel". This system uses PHP, JavaScript, SQL, HTML and CSS. This project also uses BootStrap for cosmetics. The project has three objectives, which were:
1. To maintain usability and consistency in terms of overall design and system navigation for all users.
2. To ensure efficient data handling by simplifying the searching and updating processes.
3. To enhance personalized customer experience by including interactive features.

There are three user roles for this system including:
1. Employee: able to update order statuses and view total orders made.
2. Admin: able to create, update and delete employee data and update and delete customer data. Additionally, admin is able to view order feedbacks, update product stocks and generate and print monthly sales report.
3. Customer: able to interact with system functiions such as size calculator and personality quiz. Additionally, able to add and remove items to wishlist and cart, search catalogue, proceed to payment and view current and past order details.

This system includes interactive features such as:
1. Size Finder (A calculator made for customers to find the clothes size that has the closest match to their body type.)
2. Vibe Checker (A personality quiz made to help customers identify their personality type and reccomend products that matches their results)
   
This project was completed in 6 months.
